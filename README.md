# 205AssessmentGame

GitHub link: https://github.com/jacksonbirdwater/205AssessmentGame

Controls (Mouse & Keyboard \ Gamepad)
In-Game
Movement: W/A/S/D keys \ D-Pad/Left Thumbstick
Sprint: Left Shift \ Left Shoulder Button
Block: Right Mouse Button \ Right Shoulder Button
Punch: Left Mouse Button \ Face Button Left (X/[])
Kick: E key \ Face Button Right (B/O)
